# WeChatBlackBG
微信纯黑主题 for Filza(巨魔）使用说明：放入Filza的Scripts文件夹 、 长按文件弹出菜单Script选项里选择［微信纯黑主题］
支持微信版本 < 8.0.40 已测试：8.0.55 ， 

【WeChat】使用 weui_color_sp_new.xml

【微信】使用 weui_color_new.xml

8.0.0 - 8.0.39 如需请自行修改删除 "_new" 。 

【WeChat】使用 weui_color_sp.xml

【微信】使用 weui_color.xml

之前版本不加载weui，此脚本不兼容。
